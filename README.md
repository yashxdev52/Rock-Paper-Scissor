🎮 Rock Paper Scissors Game

A simple and interactive Rock Paper Scissors game built using HTML, CSS, and JavaScript.

📌 About the Project

This project is a browser-based Rock Paper Scissors game where the player competes against the computer. The computer randomly selects Rock, Paper, or Scissors, and the winner is determined according to the classic game rules.

✨ Features

- 🎮 Play Rock, Paper, Scissors against the computer
- 🤖 Computer makes a random choice
- 🏆 Displays the winner of each round
- 📊 Keeps track of the score
- 🔄 Easy-to-use and interactive interface
- 📱 Responsive design

🛠️ Technologies Used

- HTML
- CSS
- JavaScript

🎯 Game Rules

- Rock beats Scissors
- Scissors beats Paper
- Paper beats Rock
- If both players choose the same option, the round is a draw.
